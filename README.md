# Food Delivery Admin Panel

## Overview
Admin panel for managing products and customer orders.

## Features
- Add Products
- Delete Products
- View Product List
- Manage Orders

## Tech Stack
- React.js
- React Router
- JavaScript (ES6+)
- Axios
- CSS3
- Vite
